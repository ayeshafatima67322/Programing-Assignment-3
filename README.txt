C++ ASSIGNMENT — 11 PROGRAMS

Each .cpp file is a separate program. Open one file at a time in Code::Blocks,
Dev-C++, Visual Studio Code (with a C++ compiler), or another C++ IDE.
Compile and run each program separately.

Important assumptions used where the question does not specify a detail:
1. Electricity bill uses progressive slabs; late fee is calculated after surcharge.
2. Traffic journey is not allowed if the licence is invalid or the vehicle is unregistered.
3. Premium shopping discount is applied after the purchase-based discount.
4. ATM verification is flagged for withdrawals above Rs. 50,000; the program still
   reports the transaction as allowed subject to verification.
5. Driver cancellation means the customer is not charged a ride fare and the
   Rs. 300 penalty is charged to the driver.
6. Insurance claim amount is shown after the stated deduction; inspection or
   manager approval may still be required before actual payment.

Submission:
Upload all 11 .cpp files to your GitHub repository, then copy the repository link
and submit/share it in Google Classroom before the stated deadline.
